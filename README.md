# GALACTIC NIGHTMARES — open-source integration

Рабочая ветка: `integration/galactic-nightmares`.

Цель: браузерная пошаговая тактическая RPG 3×3 на гексагональных аренах согласно технической спецификации проекта.

## Принятые зависимости
- Phaser 3 — игровой framework, MIT.
- honeycomb-grid 4.1.5 — геометрия гекс-сетки, MIT.

## Локальный запуск
```bash
npm install
npm run dev
```

## Текущий этап
Интеграционный срез: каркас Phaser, гекс-сетка 9×9, препятствия, 3×3 тестовые юниты, выбор и перемещение с MP, поиск маршрута по шести направлениям.

## Честный статус
Не считать это релизом. Полный ростер 30 героев, 90 уникальных способностей, индивидуальные анимации, тактический AI, три законченные карты, полный боевой цикл, сохранения и тестирование на реальных устройствах ещё впереди.
